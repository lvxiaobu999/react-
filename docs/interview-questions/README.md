## 后续方向

以下主题文档随内容增长逐步创建，暂不预建空文件：

- `fundamentals.md`：JSX 与元素模型、组件设计（受控/复合组件）、事件系统、列表与表单深入。
- `hooks-and-state.md`：Hooks 实现原理、各 Hook 深入、状态管理与数据流设计。
- `rendering-and-performance.md`：Fiber 与调度、Diff 细节、并发特性、性能测量与优化案例。
- `engineering.md`：路由、权限、代码分割、测试、构建部署、SSR/RSC 与微前端。

## 使用建议

- 初次学习按主题通读；面试前重点回顾每题的「易错点/追问」。
- 涉及版本的结论（React 17/18/19 差异）答题时必须说出版本与启用条件。
- 新增或修改题目请使用 [react-interview-question-author](../../.claude/skills/react-interview-question-author/SKILL.md) skill，保持题库结构一致。
