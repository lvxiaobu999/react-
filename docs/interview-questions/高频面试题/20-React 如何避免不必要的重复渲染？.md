# 20. React 如何避免不必要的重复渲染？

> 所属主题：渲染与性能 ｜ [← 返回目录](./README.md)

## 回答要点

先用 React DevTools Profiler 找出实际瓶颈，再采取针对性手段：

- 保持状态位置合理，避免不相关的树共享高频状态。
- 用 `React.memo` 缓存符合条件的组件，用 `useMemo`/`useCallback` 缓存昂贵计算或需要稳定引用的值。
- 使用稳定的列表 key，避免不必要的状态更新。
- 大列表可考虑虚拟化；重计算可考虑拆分或移至 Web Worker。

## 易错点 / 追问

这些缓存有比较成本和维护成本；它们不保证组件永不渲染，也不应在没有证据时机械添加。
