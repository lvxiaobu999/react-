# 09. 什么是合成事件？和原生事件有什么区别？

> 所属主题：基础与组件 ｜ [← 返回目录](./README.md)

## 回答要点

合成事件（SyntheticEvent）是 React 对原生浏览器事件的跨浏览器封装。React 不把监听器逐个挂在每个 JSX 元素上，而是把事件委托到根容器统一分发（React 17 起挂载到根容器，此前挂载到 `document`）。

- 命名遵循 camelCase（`onClick`），传函数而非字符串。
- 事件对象是合成的，`e.nativeEvent` 可取原生事件；React 17 起移除了事件对象池化，可以异步持有事件对象（React 16 及更早中异步访问会读到被清空的对象）。

## 易错点 / 追问

- `e.stopPropagation()` 阻断的是 React 合成事件流的传播；同一元素上混用原生监听器时要注意触发时序差异。

追问：React 17 为什么把委托目标从 `document` 移到根容器？——支持多个 React 根共存，避免与其他库的全局事件监听互相干扰。
