# 03. 虚拟 DOM 的作用和代价是什么？

> 所属主题：基础与组件 ｜ [← 返回目录](./README.md)

## 回答要点

虚拟 DOM 是用 JS 对象描述 UI 结构的中间层。状态变化时，React 先在内存中比较新旧描述（协调/Diff），再计算必要的 DOM 操作并提交。

- **作用**：提供声明式编程模型；把“每次更新该改哪些 DOM”交给框架统一优化；同一套描述可跨平台（DOM、原生渲染、SSR 字符串）。
- **代价**：额外的对象创建、Diff 计算和内存占用。

## 易错点 / 追问

注意“虚拟 DOM 一定比直接操作 DOM 快”是误传。精准的手动 DOM 操作可以更快；虚拟 DOM 提供的是可维护性和可接受的性能下限。性能问题应靠 Profiler 定位，而不是争论抽象层快慢。
