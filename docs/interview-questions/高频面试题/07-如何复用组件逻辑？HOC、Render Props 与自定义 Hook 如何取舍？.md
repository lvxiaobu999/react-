# 07. 如何复用组件逻辑？HOC、Render Props 与自定义 Hook 如何取舍？

> 所属主题：基础与组件 ｜ [← 返回目录](./README.md)

## 回答要点

- **HOC**：接收组件并返回新组件的高阶函数，适合横切关注点（权限、埋点）。缺点：多层包装难以调试、props 命名可能冲突、逻辑来源不透明。
- **Render Props**：把“渲染什么”作为函数 prop 传入，数据流向显式。缺点：嵌套过深时可读性差。
- **自定义 Hook**：函数组件时代的主流方案。它复用**逻辑**而非状态——每次调用都是独立的状态实例；配合内置 Hook 能覆盖大部分场景。

## 易错点 / 追问

新代码优先自定义 Hook；维护类组件遗留代码时会继续遇到 HOC（如 redux 的 `connect`）。React 19 中函数组件的 ref 直接作为 prop 传递，不再需要 `forwardRef`，也减少了 HOC 处理 ref 的负担。
