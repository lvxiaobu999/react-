# 05. 受控组件和非受控组件怎么选？

> 所属主题：基础与组件 ｜ [← 返回目录](./README.md)

## 回答要点

- **受控组件**：表单值由 React state 驱动，`value` + `onChange` 组合，state 是唯一数据源。适合需要即时校验、联动、格式化或条件禁用提交的表单。
- **非受控组件**：表单值由 DOM 自己保存，用 `defaultValue` 初始化，需要时通过 ref 读取。实现简单、少一次状态更新，适合简单表单；`<input type="file">` 只能非受控。

## 易错点 / 追问

只设置 `value` 不提供 `onChange` 会得到只读输入框警告；设置 `defaultValue` 后手动改 DOM 值，React 不感知。复杂表单可评估 react-hook-form 等库——它们大量利用非受控方式减少重渲染，但应先理解原生两种模式再谈封装。
