# 12. React 18 的自动批处理是什么？和 React 17 有何区别？

> 所属主题：Hooks、状态与副作用 ｜ [← 返回目录](./README.md)

## 回答要点

批处理会把一段时间内的多个状态更新合并处理，通常减少重复渲染。React 18 使用 `createRoot` 后，自动批处理覆盖更多异步来源，例如 Promise、定时器和原生事件回调；React 17 的默认批处理主要发生在 React 事件处理器中。

## 易错点 / 追问

遇到必须在下一行代码前同步读取 DOM 的特殊场景，可评估 `flushSync`，但它会降低批处理收益，不应常规使用。旧版 root API 不应和 React 18 `createRoot` 的行为混为一谈。
