# 08. React 中组件间通信有哪些方式？

> 所属主题：基础与组件 ｜ [← 返回目录](./README.md)

## 回答要点

- **父 → 子**：props；**子 → 父**：回调函数 props。
- **跨层级**：Context 共享主题、用户等全局数据；状态管理库（Redux、Zustand 等）处理跨树共享。
- **命令式**：ref 调用子组件暴露的方法（如 `focus()`），属于最后手段。
- **URL 与全局事件**：路由参数适合可分享、可后退的状态；`window` 级自定义事件慎用，容易失控。

## 易错点 / 追问

选择顺序上，先用最低成本的局部方案，状态放最低公共父级；不要一上来就引入全局状态。
