# 学习路线与阶段目标

路线对应 README 的六个阶段。每个阶段完成的标准：能不看资料把核心概念讲给别人听，并能在 `react-app/` 中完成至少一个对应练习。题号指 `docs/interview-questions/高频面试题/` 目录下文件名中的编号，题目目录见该目录的 README。

## 阶段 1：基础

- **目标**：理解「组件是接收 props 返回 UI 的函数，数据单向流动」。
- **核心清单**：JSX 编译结果、props/state 区分、事件处理、列表与 key、受控表单、条件渲染、组件拆分时机。
- **对应题目**：题 1–9。
- **自查问题**：JSX 和 HTML 有什么区别？为什么 key 不能用数组下标？受控和非受控怎么选？

## 阶段 2：Hooks 与状态

- **目标**：正确使用常用 Hook，理解「渲染快照」与 Effect 的同步模型。
- **核心清单**：Hooks 调用顺序约束、useState 快照与函数式更新、批处理、Effect 依赖与清理、useRef、Context、自定义 Hook。
- **对应题目**：题 10–19。
- **自查问题**：为什么 setter 之后读不到新值？StrictMode 下 Effect 为什么执行两次？什么情况下该用 Context？

## 阶段 3：渲染与性能

- **目标**：理解一次更新的完整流程，能用 Profiler 定位并解决真实性能问题。
- **核心清单**：渲染与提交两个阶段、Diff 假设、memo/useMemo/useCallback 的适用条件、错误边界、Portal。
- **对应题目**：题 20–26。
- **自查问题**：useCallback 什么时候才有意义？错误边界不能捕获什么？

## 阶段 4：工程能力

- **目标**：把组件能力放进真实项目结构：路由、权限、拆包、测试、构建。
- **核心清单**：路由与代码分割、权限模型（前端展示 + 服务端鉴权）、错误处理与降级、状态管理选型、URL 状态。
- **对应题目**：题 29、32、34。
- **自查问题**：路由级代码分割要注意什么？为什么隐藏按钮不等于安全？

## 阶段 5：进阶架构

- **目标**：理解框架层能力与架构级取舍，能在方案讨论中给出有边界的建议。
- **核心清单**：Fiber 与并发渲染、React 19 新特性、SSR 与水合、RSC、微前端。
- **对应题目**：题 27–28、30–31、33、35。
- **自查问题**：并发渲染是不是并行执行？RSC 和 SSR 差在哪？什么团队才需要微前端？

## 阶段 6：实战与表达

- **目标**：用练习验证以上内容，并形成稳定的面试表达。
- **做法**：
  - 在 `react-app/` 完成 `docs/practice/` 中的练习，对照验收条件自查；
  - 用 [react-interview-coach](../.claude/agents/react-interview-coach.md) 做模拟面试，训练「结论 → 机制 → 场景 → 取舍」的表达顺序；
  - 回顾错题，把自己的最终回答补充到题库文档中。

## 进度记录建议

- 每完成一题，先自己写一版回答再对照题库要点，标记差距；
- 每完成一个阶段，在 `docs/practice/` 补一个对应练习并跑通 lint/build；
- 定期（如每两周）做一次完整模拟面试检验留存。
